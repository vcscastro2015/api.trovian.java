Fluxo Completo de Cálculos
PASSO 1: RECEITA BRUTA
├─ valor_total_bruto_ida = (quantidade_toneladas_ida × valor_tonelada_bruta_ida) + imposto_base_ida
├─ valor_total_bruto_volta = (quantidade_toneladas_volta × valor_tonelada_bruta_volta) + imposto_base_volta
└─ valor_total_bruto_viagem = valor_total_bruto_ida + valor_total_bruto_volta

PASSO 2: FATOR DE CARGA
└─ fator_carga = (tara_caminhao + quantidade_toneladas_ida + quantidade_toneladas_volta) / capacidade_carga_maxima_caminhao

PASSO 3: COMBUSTÍVEL
├─ distancia_total_km = distancia_ida_km + distancia_volta_km
├─ consumo_estimado_litros = (distancia_total_km / media_veiculo_kmL) × fator_carga
└─ valor_total_combustivel = consumo_estimado_litros × preco_combustivel_ultimo_abastecimento

PASSO 4: PEDÁGIOS
├─ valor_pedagios_ida = quantidade_pedagios_ida × valor_pedagio_por_eixo × numero_eixos_caminhao
├─ valor_pedagios_volta = quantidade_pedagios_volta × valor_pedagio_por_eixo × numero_eixos_caminhao
└─ valor_total_pedagios = valor_pedagios_ida + valor_pedagios_volta

PASSO 5: COMISSÃO DO MOTORISTA
└─ comissao_motorista = valor_total_bruto_viagem × (percentual_comissao_motorista / 100)

PASSO 6: RESULTADO FINAL
├─ valor_total_custos = valor_total_pedagios + valor_total_combustivel + comissao_motorista
├─ valor_total_liquido = valor_total_bruto_viagem - valor_total_custos
└─ margem_percentual = (valor_total_liquido / valor_total_bruto_viagem) × 100
