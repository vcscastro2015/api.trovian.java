## ✅ Estratégia de Implementação - Módulo CheckList

### **Fase 1: Estrutura Base (3-4 dias)**

**1.1 ModeloChecklist** (Template reutilizável)
- ID, nome, descricao
- tipo (VIAGEM, MANUTENCAO, DIARIO, SEMANAL)
- ativo (boolean)
- obrigatorio (boolean - bloqueia viagem se não feito)
- periodicidade (ANTES_VIAGEM, DIARIA, SEMANAL, MENSAL)
- criado_em, atualizado_em

**1.2 ItemModeloChecklist** (Itens do template)
- ID
- modelo_checklist_id (FK)
- descricao ("Verificar nível de óleo", "Conferir pneus")
- ordem (sequência de exibição)
- obrigatorio (boolean)
- permite_foto (boolean)
- permite_observacao (boolean)
- categoria (SEGURANCA, DOCUMENTACAO, MECANICA, ELETRICA)
- tipo_resposta (OK_NAO_OK, SIM_NAO, NUMERICO, TEXTO)

**1.3 ChecklistRealizado** (Registro da execução)
- ID, numero_checklist
- modelo_checklist_id (FK)
- veiculo_id (FK)
- motorista_id (FK - quem realizou)
- viagem_id (FK - opcional, se for pré-viagem)
- data_hora_inicio, data_hora_conclusao
- km_veiculo (odômetro no momento)
- status (EM_ANDAMENTO, APROVADO, REPROVADO)
- observacoes_gerais
- localização (GPS - opcional)

**1.4 RespostaItemChecklist** (Respostas dos itens)
- ID
- checklist_realizado_id (FK)
- item_modelo_id (FK)
- resposta (OK, NAO_OK, valor numérico, texto)
- observacao
- foto_url (caminho da foto/evidência)
- requer_atencao (boolean - gera alerta)

================================================================================

### **Fase 2: Checklists Padrão (2 dias)**

**2.1 CheckList Pré-Viagem** (Obrigatório antes de iniciar viagem)

✅ DOCUMENTAÇÃO
- CNH válida
- CRLV do veículo
- Seguro em dia
- Documentos da carga

✅ SEGURANÇA
- Cinto de segurança
- Triângulo e extintor
- Kit primeiros socorros
- Lanternas funcionando

✅ MECÂNICA
- Nível de óleo
- Nível de água
- Freios (teste de pedal)
- Embreagem
- Direção (folgas)

✅ PNEUS
- Calibragem (todos os pneus)
- Estado da banda de rodagem
- Estepe em condições

✅ ELÉTRICA
- Faróis (alto/baixo)
- Lanternas traseiras
- Setas
- Freio de mão
- Buzina
- Limpadores de para-brisa

✅ CARROCERIA/CARGA
- Carroceria sem avarias
- Amarração da carga
- Lonas/proteção

**2.2 CheckList Diário** (Mais simples, inspeção rápida)
- Verificação visual externa
- Luzes funcionando
- Nível de combustível
- Pneus (visual)
- Limpeza básica

### **Fase 3: Regras de Negócio & Integrações (3 dias)**

**3.1 Integração com Viagem**
```java
// Ao criar nova viagem
if (veiculo.requer_checklist_pre_viagem) {
    ChecklistRealizado ultimo = buscarUltimoChecklist(veiculo);
    
    if (ultimo == null || ultimo.data < hoje) {
        throw new Exception("CheckList obrigatório não realizado");
    }
    
    if (ultimo.status == REPROVADO) {
        throw new Exception("Veículo reprovado no CheckList. Realizar manutenção.");
    }
}
```

**3.2 Integração com Manutenção**
```java
// Se item reprovado no checklist
if (resposta.requer_atencao && resposta.resposta == NAO_OK) {
    OrdemServico os = new OrdemServico();
    os.setVeiculo(checklist.getVeiculo());
    os.setTipo(CORRETIVA);
    os.setDescricao("Problema detectado no CheckList: " + item.descricao);
    os.setObservacoes(resposta.observacao);
    os.setStatus(ABERTA);
    manutencaoService.criar(os);
    
    // Envia alerta para gestor
    alertaService.enviar("Manutenção necessária - Veículo " + veiculo.placa);
}
```

**3.3 Bloqueios Automáticos**
```java
// Veículo com checklist reprovado não pode viajar
if (checklistReprovado && !manutencaoConcluida) {
    veiculo.setStatus(BLOQUEADO);
    veiculo.setMotivo_bloqueio("CheckList reprovado - aguardando manutenção");
}
```

## 📊 Exemplo de Implementação - Entidade Principal

```java
@Entity
@Table(name = "checklist_realizado")
public class ChecklistRealizado {
    
    @Id
    @GeneratedValue(strategy = GenerationType.UUID)
    private UUID id;
    
    private String numeroChecklist; // CK-2024-00001
    
    @ManyToOne
    @JoinColumn(name = "modelo_checklist_id")
    private ModeloChecklist modeloChecklist;
    
    @ManyToOne
    @JoinColumn(name = "veiculo_id")
    private Veiculo veiculo;
    
    @ManyToOne
    @JoinColumn(name = "motorista_id")
    private Motorista motorista;
    
    @ManyToOne
    @JoinColumn(name = "viagem_id", nullable = true)
    private Viagem viagem;
    
    private LocalDateTime dataHoraInicio;
    private LocalDateTime dataHoraConclusao;
    
    private Integer kmVeiculo;
    
    @Enumerated(EnumType.STRING)
    private StatusChecklist status; // EM_ANDAMENTO, APROVADO, REPROVADO
    
    @Column(columnDefinition = "TEXT")
    private String observacoesGerais;
    
    private String localizacao; // lat,lng
    
    @OneToMany(mappedBy = "checklistRealizado", cascade = CascadeType.ALL)
    private List<RespostaItemChecklist> respostas = new ArrayList<>();
    
    // Método de negócio
    public void finalizar() {
        this.dataHoraConclusao = LocalDateTime.now();
        
        // Verifica se há itens reprovados
        boolean temItemCritico = respostas.stream()
            .anyMatch(r -> r.getRequerAtencao() && 
                          r.getResposta().equals("NAO_OK"));
        
        this.status = temItemCritico ? 
            StatusChecklist.REPROVADO : StatusChecklist.APROVADO;
    }
}
```
