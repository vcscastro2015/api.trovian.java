Agora vamos fazer um CRUD do Objeto comissão de motorista na estrutura bem definida do projeto java
Vamos ter os seguinte atributos:
    
Campos Principais
Identificação e Relacionamento:

id - INT (auto-increment, primary key)
motorista_id - INT (foreign key, NOT NULL)
viagem_id - INT (foreign key, nullable)

Valores Financeiros:

valor_corrida - DECIMAL(10,2)
percentual_comissao - DECIMAL(5,2)
valor_comissao - DECIMAL(10,2)
valor_liquido_motorista - DECIMAL(10,2)
descontos - DECIMAL(10,2) (default: 0.00)

Datas e Período:

data_corrida - DATE
data_calculo - DATETIME
data_pagamento - DATE (nullable)
periodo_referencia - VARCHAR(7) (formato: YYYY-MM)

Status e Controle:

status - ENUM('pendente', 'calculada', 'paga', 'cancelada')
tipo_comissao - ENUM('por_viagem', 'mensal', 'por_km')
forma_pagamento - VARCHAR(50) (nullable)

Informações Complementares:

quilometragem - DECIMAL(10,2) (nullable)
observacoes - TEXT (nullable)
usuario_registro_id - INT (foreign key)
created_at - TIMESTAMP (default: CURRENT_TIMESTAMP)
updated_at - TIMESTAMP (default: CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP)

Campos Opcionais

bonificacoes - DECIMAL(10,2) (default: 0.00)
penalidades - DECIMAL(10,2) (default: 0.00)
taxa_plataforma - DECIMAL(10,2) (default: 0.00)
origem - VARCHAR(255) (nullable)
destino - VARCHAR(255) (nullable)
numero_nota_fiscal - VARCHAR(50) (nullable)

	
	private Cliente cliente //Obrigatorio
	

o metodo GetMapping ter somente esses:
Um para buscar todos as comissoes com paginação
Um para buscar a Comissao pelo id
Um para buscar a Comissao pelo Cliente
